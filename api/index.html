    run_ingestion(settings, selected=SOURCE_ORDER, refresh=False, client=None)

    Ingere as fontes selecionadas para a camada bronze, de forma idempotente.

    Fontes dependentes leem snapshots bronze anteriores: authors usa propositions, votes usa votings e speeches usa deputies.

    Parameters:

    Name Type Description Default
    settings Settings

    Configuração validada.

    		 required
    selected Sequence[str]

    Subconjunto de SOURCE_ORDER; by default todas.

    		 SOURCE_ORDER
    refresh bool

    Se True, ignora o cache e grava um novo snapshot datado, by default False.

    		 False
    client CamaraClient

    Cliente já configurado (injetável em testes).

    		 None

    Returns:

    Type Description
    dict[str, Path]

    Snapshot bronze de cada fonte processada.

    Raises:

    Type Description
    ValueError

    Se alguma fonte selecionada for desconhecida.
    IngestionError

    Se a API falhar definitivamente ou não retornar registros.
    DataNotFoundError

    Se uma fonte dependente for pedida sem seu pré-requisito ingerido.

    Examples:

    >>> run_ingestion(settings, selected=["deputies"])

    Pré-processamento

    Limpeza leve de textos em português (ementas e discursos).

    A limpeza preserva a sintaxe (sem remoção de stopwords nem stemming), pois o encoder de sentenças se beneficia de frases completas; stopwords são tratadas apenas na vetorização c-TF-IDF.

    build_coauthorship_graph(authors, max_authors)

    Constrói a rede de coautoria: arestas ponderadas pelo nº de proposições em comum.

    Proposições com mais de max_authors autores (ex.: PECs de bancada) são ignoradas nas arestas, pois geram cliques que dominam a estrutura da rede; seus autores permanecem como nós.

    Parameters:

    Name Type Description Default
    authors DataFrame

    Tabela silver de autoria (proposition_id, deputy_id).

    		 required
    max_authors int

    Máximo de autores para uma proposição contribuir com arestas.

    		 required

    Returns:

    Type Description
    Graph

    Grafo não direcionado; aresta com atributo weight (proposições em comum).

    Raises:

    Type Description
    ValueError

    Se max_authors for menor que 2.

    Examples:

    >>> graph = build_coauthorship_graph(authors, max_authors=30)
>>> graph.number_of_nodes() >= 0
True
